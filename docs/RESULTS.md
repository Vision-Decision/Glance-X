# Glance-X-Lite results

Checkpoint: `Vision-Decision/Glance-X-Lite` (Qwen3.5-0.8B-Base, step 6,100).
- Training: 2 epochs, with half of the batches in each direction, on the RefCOCO family plus Glance-COCO.
- Evaluation: full splits, CUDA, bf16. Each direction is evaluated separately with the same weights.

The experiments behind this model are in
[Glanece-Training](https://github.com/Vision-Decision/Glanece-Training/blob/main/docs/RESULTS.md):
- the 4B models
- the two-way decoder
- sparse joint fusion
- `text_first` token pruning

the same distribution as part of the training data.

## Latency (ms, one H200, end to end, N = 1 / 16 / 64 / 128)

| Workload | Glance-X-Lite |
|---|---|
| one image, N requests (`image_first`) | 36 / 44 / 64 / 94 |
| one request, N cached images | 34 / 33 / 36 / 42 |
| one request, N new images, encode + search (`image_first`) | 84 / 187 / 609 / 1,143 |
| one request, N new images (`text_first`) | 38 / 181 / 658 / 1,293 |

- Inputs: one 640×480 Glance-COCO image with its first N requests, and a short request over N other images.
- Scripts: `scripts/benchmark_twoway.py` and `scripts/compare_jev.py`.
- The image cache takes 25 MB per image.
